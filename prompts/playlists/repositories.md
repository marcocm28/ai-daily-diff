# Playlist prompt — AI Repositories & Builder Tools

Read prompts/editorial.md, prompts/playlist.md and the chosen format prompt.
Set primary_playlist: repositories and prompt_profile: repositories. primary_audience must be builder.

## Focus

One useful AI repository or a purposeful artifact comparison for a concrete task. Review the original README, license, release/setup evidence and current limits.

## Specialization and delivery

Identify prerequisites, supported environment, the starting command or documented setup, expected artifact and maintenance uncertainty. Distinguish execution from documented inspection.

Write one viewer question before the title. Every story, slide, example and source
must serve that question and this playlist's description. Research all mandatory
scopes, then defer strong leads outside this brief to their proper queues. Format
and SEO choices must preserve the subject and audience level.

## Exclude

A GitHub source link alone, generic star rankings, unchanged tutorials called new releases, or setup steps invented from memory.

## When another playlist is appropriate

Use guides when the task tutorial is central and the repository incidental; architectures when a research mechanism is central; builder for mixed technical news. Choose one placement before authoring; this guidance never authorizes
secondary memberships. Rework a mismatched draft or leave it pending.

## Approval

Record playlist_review with status approved, reviewer and a specific whole-video
reason. Verify primary_audience, primary_playlist and prompt_profile agree with the
actual video and generated description before queueing. A passing technical check
or one relevant segment does not approve placement.

# Playlist prompt — AI Model Releases & Capabilities

Read prompts/editorial.md, prompts/playlist.md and the chosen format prompt.
Set primary_playlist: models and prompt_profile: models. Choose exactly one primary_audience: everyday, professional or builder.

## Focus

Verified model releases or changed model capabilities, explained around one viewer question. Compare versions only with supported evidence.

## Specialization and delivery

Choose everyday, professional or builder and keep that audience level throughout. Explain exact names, event dates, access, a useful capability and important limits.

Write one viewer question before the title. Every story, slide, example and source
must serve that question and this playlist's description. Research all mandatory
scopes, then defer strong leads outside this brief to their proper queues. Format
and SEO choices must preserve the subject and audience level.

## Exclude

App integrations presented as model releases, mixed sandbox/admin stories, architecture speculation and an agent demo whose main subject is orchestration.

## When another playlist is appropriate

Use an audience path for a coherent mixed briefing; agents for workflow coordination; architectures for documented mechanisms. Choose one placement before authoring; this guidance never authorizes
secondary memberships. Rework a mismatched draft or leave it pending.

## Approval

Record playlist_review with status approved, reviewer and a specific whole-video
reason. Verify primary_audience, primary_playlist and prompt_profile agree with the
actual video and generated description before queueing. A passing technical check
or one relevant segment does not approve placement.

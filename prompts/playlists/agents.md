# Playlist prompt — AI Agents & Practical Workflows

Read prompts/editorial.md, prompts/playlist.md and the chosen format prompt.
Set primary_playlist: agents and prompt_profile: agents. Choose exactly one primary_audience: professional or builder.

## Focus

One agent capability or coherent workflow: goal, tools, permissions, coordination, output and failure conditions. Explain how the parts interact.

## Specialization and delivery

Choose professional for operating a business workflow or builder for implementation. Keep that level. Give a documented first step and label vendor demos versus our execution.

For professional, start from a role and deliverable: what input the person provides,
what the agent may access, where approval is needed, how to inspect the output and
recover from failure. Read operating/permission documentation; do not make SDK setup
or low-level coordination the main lesson. Example: a documented document-review
workflow with a human approval point, only if the source supports all those steps.

For builder, start from the implementation question: model/runtime versions,
tool/MCP/skill interfaces, context/state boundaries, coordination, output validation
and retries. Read the actual SDK/specification or repository and its requirements.
Show a supported command or configuration and explain the test's boundary; a mock
tool does not prove the deployed agent is reliable or secure.

Adapt a Radar Workflow/Tool/Skill lead into one coherent explanation. A list of new
plugins is not an agent workflow. The title's query must identify the task or
implementation decision; the closing invitation promises further verified agent
workflows at this same level, without predicting an unknown release.

Write one viewer question before the title. Every story, slide, example and source
must serve that question and this playlist's description. Research all mandatory
scopes, then defer strong leads outside this brief to their proper queues. Format
and SEO choices must preserve the subject and audience level.

## Exclude

Mixed model news with a passing mention of computer use, integration lists without an agent workflow, and security guarantees from toy fixtures.

## When another playlist is appropriate

Use professional for a work task whose orchestration is incidental, models for a pure capability release, guides for a complete how-to question. Choose one placement before authoring; this guidance never authorizes
secondary memberships. Rework a mismatched draft or leave it pending.

## Approval

Record playlist_review with status approved, reviewer and a specific whole-video
reason. Verify primary_audience, primary_playlist and prompt_profile agree with the
actual video and generated description before queueing. A passing technical check
or one relevant segment does not approve placement.

## Vendors (`vendors/<slug>.png`)

Vendor marks are used **only as identifiers** — to say who a story is about — never as the
subject of a slide or thumbnail, and never beside a judgement about that vendor
(`PROJECT_INSTRUCTIONS.md` §8.4, `prompts/title.md`). This is nominative use, the same thing any
publication does when it names a product.

Rules for adding one, no exceptions:

1. **Official asset only**, from the vendor's own press kit or brand page. Never a redraw, never
   a HuggingFace org avatar, never generated (that would also break §2.9).
2. Record it in the table below with the exact URL it came from and the license terms, including
   whether the vendor forbids recolouring or altering proportions — several do.
3. If we don't have a clean official asset, we ship the text chip instead. `src/brand.py` falls
   back automatically, so a missing file is never a bug.

SERVING, INFERENCE & COST

A cache-reuse trick cuts long-context serving cost, and it is a config flag.

Shared request prefixes get cached once across requests instead of being recomputed for every single one.

− every request recomputes the shared prefix
+ the prefix is cached once, reused by all requests

Why it matters: Serving cost stops scaling with total tokens and starts scaling with unique tokens.

The number: 65.7% — fewer tokens billed in the example below

Run it: 9 lines, CPU, offline, <1s — code in the repo

def approx_tokens(text):
    return max(1, round(len(text) / 4))

prefix = "You are a helpful assistant. " * 40
requests = [prefix + q for q in ("hi", "why is the sky blue?", "can you say that again?")]

naive  = sum(approx_tokens(r) for r in requests)
shared = approx_tokens(prefix) + sum(approx_tokens(r[len(prefix):]) for r in requests)

print(naive, shared, round(1 - shared / naive, 3))
